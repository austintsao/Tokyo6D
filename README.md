# 東京旅遊 Tokyo Travel｜東京七日互動行程

2026/11/10（二）～11/16（一）東京七天六夜行程網站。住宿：hotel hisoca ikebukuro（池袋站西口步行 2 分鐘）。單一 HTML 檔案，不需要安裝或建置，直接用瀏覽器打開 `index.html` 就能用。
線上版：https://austintsao.github.io/Tokyo6D/

## 行程重點
- DAY 1（11/10 二）：CI 100 13:30 抵達成田機場 → N'EX 到池袋 → hotel hisoca ikebukuro 入住 → 晚餐 USHIGORO S. GINZA
- DAY 2（11/11 三）：麻布台之丘 → teamLab Borderless → 晚餐人形町今半 銀座店
- DAY 3（11/12 四）：原宿 → 表參道 → 午餐 Peter Luger（惠比壽）→ SHIBUYA SKY（15:00 入場看夕陽）→ 晚餐牛たんの檸檬 總本店（西新宿）
- DAY 4（11/13 五）：華納兄弟東京影城－哈利波特製作之旅（09:30 入場，全天，館內午餐）→ 17:40 新宿たかはし拉麵簡易晚餐 → 18:40 Alpen TOKYO 購物（營業到 22:00）
- DAY 5（11/14 六）：豐洲 → 銀座 → 小石川後樂園夜間賞楓 18:00 入場 → 晚餐從簡（飯田橋周邊）
- DAY 6（11/15 日）：上野 → 秋葉原 → 兩國 → 淺草寺 → 淺草Rockza 16:10–18:00 場次 → 晚餐
- DAY 7（11/16 一）：退房寄放行李 → 雜司谷鬼子母神堂 → 西武池袋本店伴手禮購物 → 池袋午餐 → 12:30 回飯店取行李 → N'EX 到成田（15:00 前抵達），搭 CI 105 返台

## 使用方式
1. 打開網站，日期與住宿已預設帶入，按「開始規劃」就會產生七天行程。
2. 在「更多 → 設定」輸入 Google Maps API Key，可以啟用真實地圖、路線和餐廳搜尋；沒有金鑰時會用內建示範資料。
3. 天氣使用 Open-Meteo，不需要金鑰。

> Google Maps API Key 只存在瀏覽器的 localStorage，原始碼裡沒有任何金鑰。如果要在公開網站用自己的金鑰，請在 Google Cloud Console 設定「HTTP 參照網址限制」，只允許你的 github.io 網址使用。
